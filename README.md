# WhatsApp Campaign Web v10

واجهة عربية لإدارة قائمة جهات الاتصال واستخدام WhatsApp Web يدويًا، مع Supabase Auth + Database + Row Level Security.

## الموجود في هذه النسخة
- تسجيل دخول وإنشاء حساب عبر Supabase Auth.
- رفع XLSX / XLS / CSV وقراءة الاسم والرقم داخل المتصفح.
- حفظ الاسم والرقم تلقائيًا في جدول `contacts` بعد تسجيل الدخول.
- حفظ الاستيراد على دفعات 500 سجل لتقليل مشاكل حجم الطلبات.
- تطبيع أرقام مصر مثل `010xxxxxxxxx` إلى `+2010xxxxxxxxx`.
- منع التكرار لكل مستخدم عبر قاعدة البيانات.
- أعمدة اختيارية للموافقة `opted_in` وعدم التواصل `opted_out`.
- قائمة منع محلية، ساعات هدوء، حد يومي محلي، وفاصل أدنى بين فتح المحادثات.
- WhatsApp Web: فتح محادثة مع رسالة جاهزة، ثم الضغط على **إرسال يدويًا** داخل WhatsApp. لا يوجد إرسال آلي ولا WhatsApp API في هذه النسخة.
- تسجيل تأكيدات الإرسال اليدوي في `contact_events`.

## إعداد Supabase
1. افتح Supabase SQL Editor.
2. شغّل محتوى `supabase_schema.sql`.
3. داخل التطبيق ضع Project URL و `anon/public key` فقط.
4. لا تضع `service_role` أو أي مفتاح سري داخل `index.html`.

## تشغيل على GitHub Pages
ضع `index.html` في جذر المستودع، ثم فعّل GitHub Pages من إعدادات المستودع.

> ملاحظة: ضوابط الحماية تقلل مخاطر الاستخدام غير المناسب لكنها لا تضمن عدم تقييد حساب WhatsApp.
